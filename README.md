# scholarly

This is an collaborative web app with the main purpose of managing student of cameroonian elementary schools. Initialy a group class project in NASEY (in Yaoundé, Cameroon).

Backend built with [NestJS](https://nestjs.com/) and [Prisma](https://www.prisma.io/) (MySQL).

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
